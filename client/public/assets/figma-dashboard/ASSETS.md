# Figma dashboard SVG assets

Source: `saveswitch` Figma file `lid969fsF1QKGMPbgVfZD2`, dashboard node `100:897`.

Every `.svg` in this directory is the unmodified vector export downloaded from
the Figma connector. These assets are intentionally stored as files rather than
being recreated as inline paths.

| File | Figma node | Dashboard UI role |
| --- | --- | --- |
| `date-navigator.svg` | `100:901` | Current/previous day navigator indicator in the top bar. |
| `delete-item.svg` | `100:906` | Delete action shown on saved-item rows. |
| `file-item.svg` | `100:911` | File glyph shown at the start of saved-item rows. |
| `add-subpage.svg` | `100:972` | Add button in the bottom sub-page navigator. |
| `counter-indicator.svg` | `100:980` | Blue notification/count badge used on category navigation buttons. |
| `nav-all-files.svg` | `100:976` | All-files category navigation icon. |
| `nav-copied-text.svg` | `100:985` | Copied-text category navigation icon. |
| `nav-images.svg` | `100:990` | Images category navigation icon. |
| `nav-files.svg` | `100:996` | Files category navigation icon. |
| `nav-links.svg` | `100:1001` | Links category navigation icon. |
| `upload.svg` | `100:1004` | Upload control in the top-right dashboard toolbar. |
| `profile.svg` | `100:1006` | Profile control in the top-right dashboard toolbar. |

The individual saved-row and category icon instances in Figma reuse these same
exported vectors; no raster icons are required for the dashboard.
